# Nombre del proyecto
cafe-origen

## Descripción
(La funcion del proyecto es ver los productos que se compran en una cafeteria)

## Tecnologías utilizadas
- HTML y CSS para el diseño 
JavaScript para la animacion de la pagina 
JSON 
XML
Node.js
Git y Github

## Cómo ejecutar o consultar el proyecto
Para ejecutarlo tenemos que descargar las carpeta .zip , despues abrir una terminar y ejecutar node server.js para revisar si esta conectado al localhost3500, viendo que si esta conectador podemos ingresar y visualizar toda la infromacion
